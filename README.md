## Tecnologías que podrían utilizarse

- HTML: estructura de la página web.
- CSS: diseño y estilos de la aplicación.
- JavaScript: interactividad y selección de productos.
- Python: programación de las funciones principales.
- Flask: conexión entre la página y el servidor.
- MySQL: almacenamiento de clientes, productos y pedidos.
- Git: control de versiones del código.
- GitHub: almacenamiento y colaboración en el proyecto.
- Trello: organización de las actividades.
- Jira: administración y seguimiento de tareas.
