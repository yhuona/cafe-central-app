# App Cafeteria Central 
<h2>Acerca de</h2>
<p>¡<strong>Aplicación web</strong> para tener la cafeteria desde la comodidad de tu hogar! Consulta el <b>menú y realizar pedidos</b>  desde tus dispositivos móviles o computador.</p>
<h4>¡Menos Problemas!<p><em>"Hemos resuelto problemas que tienen que ver con las funciones iniciales"</em></p></h4>

- Funciones intuitivas en la interfaz
  - Vista de los detalles del producto
- Servicios más accesible para todos los usuarios

<hr>

### Funcionalidades Principales 
<strong>Consulta Menú</strong> | <strong>Visualización de Precios</strong> | <strong>Registro de Clientes</strong> |
<br><strong>Selección de Productos</strong> | <strong>Creación de Pedidos</strong> | <strong>Consulta del estado de el Pedido</strong>

#### Tecnologías que podrían utilizarse

- HTML: estructura de la página web.
- CSS: diseño y estilos de la aplicación.
- JavaScript: interactividad y selección de productos.
- Python: programación de las funciones principales.
- Flask: conexión entre la página y el servidor.
- MySQL: almacenamiento de clientes, productos y pedidos.
- Git: control de versiones del código.
- GitHub: almacenamiento y colaboración en el proyecto.
- Trello: organización de las actividades.
- Jira: administración y seguimiento de tareas.
